Root cause

Embedded Continue to Shopify Approve charge (and any other admin.shopify.com handoff) issued a 302 into the app iframe. Admin sends X-Frame-Options: DENY, so the iframe showed “admin.shopify.com refused to connect”. Same class of failure on Billing / Mappings when in-app links dropped shop / host / embedded.

What we changed

  • Approve-charge now returns 200 HTML with App Bridge + window.open(url, "_top") (never a 302 to Admin inside the iframe).
  • Billing returnUrl is the Admin re-embed URL so the merchant lands back in the iframe after Approve.
  • In-app Billing / Mappings links keep shop, host, embedded, id_token.
  • Live on Fly: https://filter-locale-bridge.fly.dev — image deployment-01M1JEA6V89CF8Q0TSAP117RK3 (Thu 3 Sep 2026 02:32 BST; includes the handoff fix).
